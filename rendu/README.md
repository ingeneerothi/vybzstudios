## Enregistrer la vidéo dans la galerie

**iPhone**

1. Dans Safari, touche le lien `vybz-studios-pub-4k-galerie.mp4` ci-dessus, puis « Télécharger ».
2. Ouvre l'app Fichiers, va dans « Téléchargements » et touche la vidéo.
3. Touche le bouton Partager, puis « Enregistrer la vidéo ». Elle est maintenant dans Photos.

**Android**

1. Dans Chrome, touche le lien `vybz-studios-pub-4k-galerie.mp4` ci-dessus : le téléchargement démarre.
2. La vidéo apparaît dans la Galerie (album « Download ») ou dans Google Photos.

Si la vidéo ne se lit pas sur ton téléphone, télécharge `vybz-studios-pub-4k.mp4` de la même façon.
